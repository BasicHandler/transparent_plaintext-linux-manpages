# transparent_plaintext-linux-manpages

The official Linux manual pages, converted to plaintext.

## What this is
This repository contains the plaintext content of the Linux man-pages "book" originally hosted as a PDF at [kernel.org](https://kernel.org). 

The purpose is to provide the documentation in a transparent, readable format without PDF overhead.

## Format
- **Source**: Linux man-pages project (kernel.org)
- **Format**: Plaintext (.txt)
- **Status**: No formatting changes, no external commentary. This is a neutral, unfiltered mirror of the source documentation. Plaintext Linux man-pages v6.9 from kernel.org strips some noise out +  a needed raw webpage to query using the browser/CLI ##### This is an alternative to the ear-fck infested manuals in Android, but in case a tin foil scuba session has to be: offline-ready documentation, to simplify the native HTML Viewer rider on a journey, even without a menu in sight. #####
